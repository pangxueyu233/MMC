# Upload Instructions

Use this directory as the public GitHub/reviewer-facing package.

Recommended upload scope:

- Include every file inside `public_release/`.
- Do not include the parent repository's exploratory Markdown notebooks, image-cache folders, Word documents, local HTML exports, or controlled-data files.
- If this package is copied to a new repository, make `public_release/README.md` the repository root `README.md`.

Before upload, run the checks in `release_checklist.md`.
